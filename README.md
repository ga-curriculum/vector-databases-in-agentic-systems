## About

This module solves the "amnesia problem" of AI agents by introducing vector databases as external memory systems. You'll learn how Retrieval-Augmented Generation (RAG) transforms agents from confident hallucination machines into grounded, factual systems that can access dynamic, private information.

### Learning Objectives
By the end of this session, learners will be able to:

- **Identify** the amnesia problem in base LLMs and explain how vector databases solve it
- **Distinguish** between traditional databases and vector databases using semantic similarity
- **Implement** the three core steps of RAG systems: Embed, Index, and Search
- **Integrate** vector retrieval into an agent's ReAct framework for grounded reasoning
- **Recognize** common pitfalls and trade-offs in production RAG systems
